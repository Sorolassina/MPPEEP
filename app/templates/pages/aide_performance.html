📊 Guide du Module Performance

Le module Performance vous permet de définir, suivre et mesurer les objectifs organisationnels à travers une hiérarchie structurée : Programmes → Objectifs Globaux (OG) → Objectifs Spécifiques (OS) → Indicateurs. Ce guide vous accompagne dans l'utilisation complète du système.

🏗️ Architecture du Système de Performance

Le système de performance suit une hiérarchie claire permettant de structurer les objectifs de manière logique et mesurable. Chaque niveau est lié au niveau supérieur, créant une chaîne de responsabilité et de mesure.

📋 Programme
🎯 Objectif Global (OG)
📌 Objectif Spécifique (OS)
📊 Indicateur de Performance

🎯 Objectif Global (OG)

Objectif stratégique à long terme, rattaché à un Programme et à un Résultat Stratégique. Il définit la direction générale à suivre.

📌 Objectif Spécifique (OS)

Objectif opérationnel à court/moyen terme, rattaché à un Objectif Global (OG). Il décompose l'OG en actions concrètes et mesurables.

💡 Note importante : Un Objectif Spécifique (OS) peut être rattaché à un Objectif Global (OG) pour créer une hiérarchie claire. Les indicateurs sont toujours rattachés à un OS, permettant de mesurer la réalisation des objectifs opérationnels.

🎯 Gestion des Objectifs de Performance

Types d'Objectifs

🌍 Objectif Global (OG)

Caractéristiques :
• Rattaché à un Programme
• Lié à un Résultat Stratégique
• Vision à long terme
• Peut avoir un code (ex: OG01)

📋 Objectif Spécifique (OS)

Caractéristiques :
• Rattaché à un Objectif Global (OG)
• Actions concrètes et mesurables
• Vision à court/moyen terme
• Peut avoir un code (ex: OS01)

Créer un Objectif

  1. 1
    Accédez à "Performance → Objectifs" et cliquez sur "➕ Nouvel Objectif"
  2. 2
    Sélectionnez le type : Global (OG) ou Spécifique (OS)
  3. 3
    Remplissez les informations :
    • Code : Identifiant unique (ex: OG01, OS01) - optionnel
    • Titre : Nom clair et explicite de l'objectif
    • Description : Détails et contexte
    • Période : Année ou période de réalisation
    • Statut : En cours, Atteint, En retard, etc.
  4. 4
    Pour un Objectif Global (OG) :
    • Sélectionnez le Programme concerné
    • Sélectionnez le Résultat Stratégique associé
  5. 5
    Pour un Objectif Spécifique (OS) :
    • Sélectionnez l'Objectif Global (OG) auquel il est rattaché
  6. 6
    Définissez les valeurs :
    • Valeur cible : Objectif à atteindre
    • Valeur actuelle : État actuel (calculée automatiquement à partir des indicateurs)
  7. 7
    Optionnel : Assignez un responsable et enregistrez

✅ Astuce : Les objectifs sont automatiquement triés par code (s'ils existent) puis par date de création. Utilisez des codes cohérents pour faciliter l'organisation.

📊 Gestion des Indicateurs de Performance (KPIs)

Les indicateurs permettent de mesurer objectivement la performance et l'atteinte des objectifs. Chaque indicateur est rattaché à un Objectif Spécifique (OS) et permet de calculer automatiquement la valeur actuelle de l'objectif.

Créer un Indicateur

  1. 1
    Accédez à "Performance → Indicateurs" et cliquez sur "➕ Nouvel Indicateur"
  2. 2
    Sélectionnez l'Objectif Spécifique (OS) : L'indicateur doit être rattaché à un OS
  3. 3
    Informations de base :
    • Nom : Nom explicite de l'indicateur
    • Description : Contexte et méthode de calcul
    • Année : Année de suivi
    • Catégorie : Qualitatif, Quantitatif, Efficacité, etc.
  4. 4
    Valeurs et objectifs :
    • Valeur cible : Objectif à atteindre
    • Valeur actuelle : État actuel (si ≠ 0, un document justificatif est requis)
    • Unité de mesure : %, €, jours, unités, etc.
  5. 5
    Sens d'appréciation :
    • ↑ Haut : Plus la valeur est élevée, mieux c'est (ex: taux de satisfaction)
    • ↓ Bas : Plus la valeur est basse, mieux c'est (ex: taux d'erreur)
  6. 6
    Seuils d'alerte : Définissez les niveaux minimum et maximum acceptables
  7. 7
    Informations complémentaires :
    • Méthode : Méthode de calcul ou d'évaluation
    • Mode de collecte : Routine, Enquête, Autres
    • Fréquence : Journalier, Hebdomadaire, Mensuel, Trimestriel, Annuel
    • Source des données : Système, Enquêtes, Comptabilité, etc.
  8. 8
    Projections : Définissez les cibles pour N+1 et N+2 si nécessaire
  9. 9
    Document justificatif : Si la valeur actuelle est différente de 0, vous devez joindre un document justifiant cette valeur (PDF, Word, Excel, images)

⚠️ Important : Lorsque vous renseignez une valeur actuelle différente de 0, le système exige un document justificatif. Cela permet de justifier la valeur renseignée et de détecter d'éventuels biais ou erreurs dans la saisie des données.

💡 Calcul automatique : La valeur actuelle d'un Objectif Spécifique (OS) est automatiquement calculée comme la moyenne des valeurs actuelles de ses indicateurs. De même, la valeur actuelle d'un Objectif Global (OG) est la moyenne des valeurs actuelles de ses OS, et ainsi de suite jusqu'au Programme.

📄 Rapports de Performance

Le module Performance permet de générer différents types de rapports pour présenter les résultats, analyser les tendances et documenter les performances.

Types de Rapports Disponibles

📋 Cadre de Performance

Document structuré présentant l'ensemble du cadre de performance avec les objectifs et indicateurs

📊 Rapport Annuel

Rapport complet sur l'année écoulée avec analyse des résultats et tendances

📝 Lettres d'Engagement

Documents d'engagement pour les responsables de programmes et de BOP

Générer un Rapport

  1. 1
    Accédez à "Performance → Rapports"
  2. 2
    Sélectionnez le type de rapport souhaité
  3. 3
    Configurez les paramètres (période, programmes, etc.)
  4. 4
    Cliquez sur "Générer" pour créer le rapport au format PDF

✨ Bonnes Pratiques

  • 🎯 Définir des objectifs SMART : Spécifiques, Mesurables, Atteignables, Réalistes, Temporels
  • 📊 Limiter le nombre d'indicateurs : Privilégier 5-10 KPIs clés par domaine pour éviter la surcharge d'information
  • 🔄 Mettre à jour régulièrement : Maintenir les valeurs actuelles à jour pour un suivi efficace
  • 📎 Justifier les valeurs : Toujours joindre un document justificatif lorsque la valeur actuelle est différente de 0
  • ⚠️ Fixer des seuils pertinents : Définir des seuils d'alerte réalistes pour chaque indicateur
  • 📅 Réviser périodiquement : Examiner et ajuster les objectifs trimestriellement ou annuellement
  • 📈 Analyser les écarts : Identifier les causes des écarts et prendre des actions correctives
  • 👥 Partager les résultats : Communiquer les résultats avec les équipes concernées pour favoriser l'amélioration continue
  • 🔗 Maintenir la hiérarchie : S'assurer que les OS sont bien rattachés aux OG et les indicateurs aux OS
  • 🏷️ Utiliser des codes cohérents : Adopter une nomenclature claire pour faciliter l'organisation (ex: OG01, OS01)

❓ Questions Fréquentes

Comment calculer la valeur actuelle d'un objectif ?

La valeur actuelle est calculée automatiquement par le système :

  • Pour un OS : Moyenne des valeurs actuelles de ses indicateurs (en tenant compte du sens d'appréciation)
  • Pour un OG : Moyenne des valeurs actuelles de ses OS
  • Pour un Résultat Stratégique : Moyenne des valeurs actuelles de ses OG
  • Pour un Programme : Moyenne des valeurs actuelles de ses Orientations Stratégiques

Pourquoi dois-je joindre un document justificatif ?

Le document justificatif est requis pour garantir la traçabilité et la fiabilité des données. Il permet de justifier la valeur renseignée et de détecter d'éventuels biais ou erreurs dans la saisie.

Quelle est la différence entre un OG et un OS ?

Un Objectif Global (OG) est un objectif stratégique à long terme, rattaché à un Programme et à un Résultat Stratégique. Un Objectif Spécifique (OS) est un objectif opérationnel à court/moyen terme, rattaché à un OG, qui décompose l'OG en actions concrètes et mesurables.

Comment le sens d'appréciation affecte-t-il le calcul ?

Le sens d'appréciation permet de normaliser les valeurs avant le calcul de la moyenne :

  • Haut (↑) : Plus la valeur est élevée, mieux c'est. Le taux de réalisation est calculé comme (valeur_actuelle / valeur_cible) × 100
  • Bas (↓) : Plus la valeur est basse, mieux c'est. Le taux de réalisation est calculé comme (valeur_cible / valeur_actuelle) × 100

Les taux normalisés sont ensuite moyennés pour calculer la valeur actuelle de l'OS.
